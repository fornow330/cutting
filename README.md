# cutting

《怪潮幸存者》—— 浏览器端单文件割草 / 塔防小游戏（Canvas，零外部依赖）。

在线游玩：https://fornow330.github.io/cutting

## 关于源码（不开放）

本仓库不含可读源码，采用三层处理：

1. **混淆**：游戏脚本经标识符重命名、字符串数组化（Base64）、字符串拆分、死代码注入等处理；
2. **加密**：混淆产物连同样式、UI 一起用 AES-256-GCM 加密为单一密文；
3. **分片+拆钥**：密文切成 4 片存放在 `chunks/`，解密密钥也被拆成 4 段分别藏在各分片头部，缺任意一片都无法还原。

仓库内没有明文、没有完整密钥。请勿转载、反编译、二次发布或用于商业用途。

## 玩法

自动开火，走位保命，吃经验晶体升级；活过每一波，把星核带回基地永久变强。
