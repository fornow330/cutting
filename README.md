# cutting

《怪潮幸存者》—— 浏览器端单文件割草 / 塔防小游戏（Canvas，零外部依赖）。

在线游玩：https://fornow330.github.io/cutting

## 关于源码

- 本仓库**不开放源代码**：页面主体（样式、UI、游戏逻辑）以 AES-256-GCM 加密后拆成 10 个分片存放于 `chunks/`，运行时由 `index.html` 拉取、解密并装配。
- 仓库内不存在可读的明文源码；请勿转载、分发、反编译或二次发布。
- 若需要可运行的单文件版本，属于未公开内容，不在本仓库提供。

## 玩法

自动开火，走位保命，吃经验晶体升级；活过每一波，把星核带回基地永久变强。
